5输出视频（口播短视频）

图片会被裁剪铺满画面；视频背景会循环播放到语音结束
音乐不足片长时自动循环铺满；开着闪避时，人声一出来音乐就会被压下去， 停顿时再抬回来。仓库 assets/bgm_demo.mp3 是一段可自由使用的示例配乐。
打字机按「累计前缀」逐字渲染：每多一个字就多一条字幕事件， 关键词从第一个字起就染高亮色，打完整行后保持到本屏结束。 自适应会按本屏语音时长反推每字秒数（下限 type_min）。
大字样式默认：每行 4 字、每屏 3 行、字号＝画面宽 ×14.7%、 粗黑体、首行隔行染高亮色。高亮色支持 #00F090 或 ASS 的 &H0090F000。
合成用 ffmpeg 本地转码，1080×1920 一条约 5~20 秒（视 CPU）。 视频长度 = 配音时长 + 尾部留白，画面会自动跟着语音走，不会把音频截断。

6封面（1080×1920 竖图）

「标题列」取不到值时自动从「仿写文案」里截一句； 跑了发布素材包的话会先有「推荐标题」列，封面会优先用它。 封面在本地用 Pillow 画，不调任何生图接口。
